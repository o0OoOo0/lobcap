## 한 문단 요약

크립토 L2 데이터를 직접 수집해 호가창 리플레이 시뮬레이터를 만들고, 그 위에서
마켓메이킹 전략의 손익을 **스프레드 수익 / 역선택 비용 / 재고 손익 / 헤지 비용**으로 분해한다.
큐 순위·레이턴시·수수료 등 백테스트 가정을 전부 파라미터화해 "어떤 가정에서만 수익이 나는
전략"과 "비관적 가정에서도 살아남는 전략"을 구분한다.

여기에 두 가지를 더한다.
- **Coinbase L3 데이터로 큐 위치의 "정답"을 만들어** L2 기반 가정 모델을 캘리브레이션한다.
- **FPGA로 하드웨어 호가창 빌더를 구현**해 소프트웨어 참조 구현과 bit-exact 검증하고,
  Python / C++ / FPGA 세 경로의 레이턴시를 **실측**해 시뮬레이터에 주입한다.

마지막으로 ETF LP의 구조를 축소한 **페어밸류 기반 호가 + 크로스 거래소 헤지**를 실험한다.

**프로젝트의 정체성은 "정직한 평가"다. 의심의 대상은 MM 전략이 아니라 우리의 측정 도구다.**

## 확정된 선택

| 항목 | 결정 | 한 줄 근거 |
|---|---|---|
| 주 데이터 | **Binance USDT-M perp 직접 수집** | 24시간, 무제한 기간, 수집기 구축 경험 자체가 산출물 |
| 보조 데이터 | **Tardis.dev Coinbase L3 (무료 구간)** | 큐 위치 정답. Binance로는 원리적 불가 |
| 서버 | **Oracle Cloud Always Free (도쿄)** | 영구 무료, 200GB, 미국 리전 아님 |
| 시장 | **크립토 우선, 국내 주식은 스트레치** | 공매도 제약으로 국내는 라이브 검증 불가 |
| FPGA 역할 | **피드 핸들러 / 북 빌더** (전략 아님) | 실제 MM 회사의 FPGA 용도와 동일 |
| Phase 4 | **페어밸류 + 헤지** (시그널 스큐 대체) | ETF LP 직무와 직결 |

자세한 근거는 `02_DECISIONS.md`.

## 전체 흐름

```
Phase 0    인프라              L2 수집기 · 재구성 · 리플레이 시뮬레이터        3주
Phase 0.5  L3 큐 정답 ★신규    Coinbase L3로 큐 모델 캘리브레이션            2~3주
Phase 1    나이브 MM           대칭 ±k틱 호가 → 손익 4분해 회계 틀           2주
Phase 2    재고 인지 MM        A-S 벤치마크 → 스프레드-역선택 트레이드오프    3주
Phase 3    가정 스트레스       큐 × 레이턴시(실측) × 수수료 히트맵           3주
Phase 4    페어밸류 + 헤지     ETF LP 축소판, 크로스 거래소                  3주
Phase 5    라이브 갭           페이퍼 트레이딩 3~4주, 괴리 분해              병행
FPGA 트랙  F0~F4               환경 → 북 빌더 → 검증 → 레이턴시 실측         8~10주 병렬
(스트레치) 국내 KRX vs NXT     이원화 시장 미시구조 관측 연구                2~3주
```

총 16주 기준. 시간이 모자랄 때 자르는 순서는 `01_PROJECT_PLAN.md` 참조.
